# Launch Checklist (to actually sell and receive money)

## 1) Choose sales channel (requires your account)
- [ ] **Gumroad / Payhip / Lemon Squeezy**: easiest for digital downloads and payouts
- [ ] **Etsy**: good for discovery (optimize title/tags/mockups)
- [ ] **Shopify / own site**: more control, more setup

## 2) Set up payment/payout to your wallet or bank
- [ ] Create/verify seller account and connect payout method supported by the platform
- [ ] If you want crypto/wallet cashout, use a platform/processor path that supports it in your jurisdiction and complies with terms/taxes (configure this yourself)
- [ ] Confirm tax/profile settings and refund policy

## 3) Package the product
- [ ] Zip the folder: `ai-freelancer-prompt-pack` (README, prompts, quickstart, listing copy optional)
- [ ] Add a cover/thumbnail image (Canva) and 2-3 preview screenshots/mockups
- [ ] Set price (active flash sale: $5 USDC per pack, $12 USDC bundle)

## 4) Publish listing
- [ ] Use title/description/tags from `listing-copy.md`
- [ ] Upload files, set delivery as instant digital download
- [ ] Add license/usage terms and support/contact info

## 5) Drive first traffic
- [ ] Share a useful sample prompt on X/LinkedIn/Reddit/community where allowed
- [ ] Post a short demo (how a prompt turns messy notes into a proposal/update)
- [ ] Offer limited launch discount, collect feedback, iterate

## Success metrics to monitor
- Views/clicks, conversion rate, revenue, refunds, common questions (improve listing/prompts accordingly)
